# BlatUI Starter

### A Laravel app pre-wired with [BlatUI](https://blatui.remix-it.com) — shadcn/ui for the BLAT stack (Blade · Laravel · Alpine · Tailwind).

</div>

---

This is the BlatUI starter kit. It lives in the BlatUI monorepo at
[`anousss007/blatui`](https://github.com/anousss007/blatui) under `apps/starter/`, and its BlatUI
components stay in lock-step with the library (regenerated by `scripts/build-starter.sh`, guarded
in CI) — so a fresh copy always ships the current components, all present, ready to render.

## Get started

Scaffold a new app from this directory with [degit](https://github.com/Rich-Harris/degit)
(no history, no template-repo needed):

```bash
npx degit anousss007/blatui/apps/starter my-app
cd my-app
```

Then boot it:

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate          # creates the sqlite db + session/cache tables
npm install && npm run build # or: npm run dev
php artisan serve
```

Open <http://localhost:8000> — the landing page. `/dashboard`, `/login` and `/register` are wired too.

## What's inside

- **Laravel 13** · **Tailwind CSS v4** · **Alpine.js 3** · Vite.
- The full **BlatUI component set** copied into `resources/views/components/` — you own every line:
  - `ui/` — 180 component families (376 files), rendered as `<x-ui.*>`.
  - `block/` — the 8 dashboard/sidebar building blocks (`nav-user`, `nav-main`, `nav-projects`,
    `nav-secondary`, `team-switcher`, `version-switcher`, `search-form`, `file-tree`), rendered as
    `<x-block.*>`.
  - `layouts/app.blade.php` — the base HTML layout (`<x-layouts.app>`) with a no-flash theme script.
- Foundations wired: `resources/css/app.css` → `@import './blatui.css'` (Tailwind + theme tokens),
  `resources/js/app.js` → `import './blatui.js'` (boots Alpine + the BlatUI engine: components +
  calendar).
- Pre-built pages, each extending `<x-layouts.app>`:
  - `/` — marketing landing (`resources/views/landing.blade.php`)
  - `/dashboard` — analytics dashboard with the sidebar block
  - `/login`, `/register` — auth screens
- Theme tokens are CSS variables — recolor everything from the BlatUI
  [theme editor](https://blatui.remix-it.com/themes) and paste into `resources/css/blatui.css`.

## Charts (opt-in)

The default bootstrap is charts-free, so apps that don't chart never pull in ApexCharts.
`resources/js/blatui-charts.js` ships alongside — to enable `<x-ui.chart>`:

```bash
npm install -D apexcharts
```

then register it in `resources/js/app.js`:

```js
import Alpine from 'alpinejs';
import { registerBlatUI } from './blatui-core.js';
import { registerCharts } from './blatui-charts.js';

registerBlatUI(Alpine);
registerCharts(Alpine);
window.Alpine = Alpine;
Alpine.start();
```

## Add more components

Everything is already here, but the CLI is installed if you want to re-pull or explore:

```bash
php artisan blatui:add <component>     # e.g. command, date-picker, sonner
php artisan blatui:list                # browse everything
```

## Add real auth

The auth screens are UI only. For working authentication, layer Laravel's auth on top and keep
the BlatUI forms:

```bash
composer require laravel/breeze --dev
php artisan breeze:install blade
```
