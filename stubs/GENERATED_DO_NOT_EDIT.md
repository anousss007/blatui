# ⚠️ Generated directory — do not hand-edit

Everything under `packages/blatui/stubs/` (`ui/`, `foundations/`, `registry.json`) is
**generated** from the authored source in `apps/demo/` by `scripts/build-package.sh`.

Edit the component in **`apps/demo/resources/views/components/ui/<name>.blade.php`**, run
`bash scripts/build-package.sh` from the repo root, and commit both. CI rejects any PR where
this directory drifts from the authored source.

See the repo root [CONTRIBUTING.md](../../../CONTRIBUTING.md).
